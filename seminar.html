Seminar — From Foundations to Autonomous Agents

Three Saturdays — 10:00 – 16:00 — PC-Pool 9.115

Overview

A four-session companion to the lecture course. Each session bundles one or more Jupyter notebooks that build the corresponding lecture material from first principles in code. The seminar runs three times per cohort with the same materials; choose whichever Saturday fits your schedule.

All notebooks open directly in Google Colab from the QR codes in the seminar slides. No local install is required; a free Colab account is sufficient. GPU is helpful for Session 2 but not required (CPU runs take a few extra minutes).

Sessions

  • Session 1 — Foundations. Tokenisation, word embeddings, scaled dot-product attention. Build TinyGPT from scratch.
  • Session 2 — Training. Next-token pre-training on Tiny Shakespeare. Fine-tuning a pre-trained checkpoint on a small author-style dataset.
  • Session 3 — Alignment. Zero-shot, few-shot, chain-of-thought prompting. Build a retrieval-augmented generation pipeline from scratch.
  • Session 4 — Agents. The ReAct loop: tool calls, observations, autonomous problem solving with a small instruction-tuned model.

Slides

Slide decks for each session are password protected. Students receive notebook access through the QR codes embedded in the slides during the seminar itself.
