08: Agents and Tools

Monday, 29 June 2026, Hörsaal 9.122

Overview

A chat model is sealed: it can only ever emit text into a box. The lecture works through what it takes to let it look things up and act. Retrieval-augmented generation opens the weights to a live corpus. Tool calling lets the model write a function call as text and have an executor run it. The ReAct loop stitches the two into agents that plan, observe, and recover. The session ends on the failure modes that come with agency: compounding errors, blast radius, prompt injection, and the question of where the human stays in the loop.

Topics

  • Hallucinations and the two memory limits: training cutoff and finite context window
  • Retrieval-augmented generation: embed, retrieve top-K, ground the answer
  • Retrieval vs. long context: when to select, when to paste everything
  • Anatomy of an agent: planning, memory, tools (the agent is the loop, not the model)
  • The ReAct loop: thought, action, observation, repeat
  • How text becomes an action: tool schemas, constrained JSON, the executor holds the keys
  • Workflows before agents: fix the path where you can, leave autonomy for last
  • Agent memory mapped to human memory: working, declarative, procedural
  • Multi-agent systems: when parallel subtasks justify the token cost
  • The Model Context Protocol: one wire format, M+N adapters instead of M×N
  • A worked example: Claude Code as a coding agent in production
  • The arithmetic of long chains: 95% per step is 36% after twenty
  • Blast radius: search < write < execute < pay
  • Prompt injection and the lethal trifecta: private data + untrusted content + outbound channel
  • Autonomy as a dial, gated by reversibility
