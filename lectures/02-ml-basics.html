02 — Machine Learning Basics

Monday, 20 April 2026 — Hörsaal 9.122

Overview

This lecture introduces the foundational concepts of machine learning. Starting from Mitchell's definition of learning, we cover how data is represented as design matrices and feature vectors, the distinction between supervised and unsupervised learning, and how models are trained and evaluated. The lecture concludes with the perceptron algorithm as a first concrete example of a learning algorithm.

Topics

  • What is machine learning? Experience, tasks, and performance (Mitchell, 1997)
  • Supervised vs. unsupervised learning
  • Datasets, instances, features, and the design matrix
  • Classification: spam filtering as a running example
  • Labels, one-hot encoding, binary vs. multiclass classification
  • Performance measures: accuracy, precision, recall, F1-score
  • Training, development, and test splits
  • The perceptron algorithm: artificial neurons, weights, and the update rule
  • Linear separability and hyperparameters
